usage: motion_diagnosis.py [-h] --run RUN --out OUT --config-sha CONFIG_SHA
                           --seal-sha SEAL_SHA

Independent saved-array K1.2 motion audit; no policy or simulator code. The
checker reopens the exact original sources, verifies their array bytes, and
independently enumerates every declared ordered-window comparison. It does not
import production loading, metric, reporting or execution code.

options:
  -h, --help            show this help message and exit
  --run RUN
  --out OUT
  --config-sha CONFIG_SHA
  --seal-sha SEAL_SHA
