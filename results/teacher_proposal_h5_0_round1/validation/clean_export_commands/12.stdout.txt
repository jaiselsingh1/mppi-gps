usage: report_teacher_proposal.py [-h] --run RUN --out OUT
                                  [--saved-diagnostics SAVED_DIAGNOSTICS]

Render H5 metadata, saved scalar events and every recorded learning point. Raw
arrays, NPZs and checkpoints are never opened. External ledger/audit hashes
are retained as declarations from the hash-bound diagnostic extract; rendering
does not repeat that audit or certify an incomplete scientific contrast.

options:
  -h, --help            show this help message and exit
  --run RUN
  --out OUT
  --saved-diagnostics SAVED_DIAGNOSTICS
