**Verdict: Stage 1 is not ready for the proposed novelty, superiority or convergence claims.** A narrower description survives: this implementation can distill simulator-based policy-centered sampled improvements into a reactive policy on a custom Walker task, and a decreasing perturbation schedule improves one controlled LQR diagnostic. Neither is by itself a new general contribution. The closest literature overlap is substantial, the existing reset set is development data, and long-horizon CPU/GPU label and acceptance parity remains unresolved.

## Independent execution checks

### One label, independently reconstructed

`tests/test_core_independent_audit.py` derives point-mass dynamics directly from mass.3, damping1, gear.1, timestep.02; solves the terminal Riccati equation independently; generates the exact seeded Gaussian draws; clips actions; propagates analytic dynamics; recomputes stage/terminal costs; solves temperature with Brent's method rather than the production bisection; computes weights, ESS, mean plan, first-action label, clipping fraction and every reported E-step cost. Trajectories, costs, weights and all result fields agree at the recorded tolerances. [Trace result](audit_evidence/independent_label_trace.json).

The mathematical reconstruction is a controlled LQR label, not a claim that every saved Walker label is reproducible. Existing saved Walker label files do not contain the complete input state/warmstart/noise manifest. Walker CPU/GPU checks use actual saved trained-policy states and have the unresolved result above. The additional M-step trace reconstructs a small actor's forward pass, analytic gradients, one Adam update and saved-policy inference using independent NumPy calculations; see `tests/test_mstep_independent_audit.py` and [M-step trace](audit_evidence/mstep_independent_trace.json). Maximum gradient, parameter and deployed-action discrepancies are4.61e−9,1.06e−8 and6.94e−9, respectively; this test passed locally and on the server.

### External MPPI differential

The independently installed `pytorch-mppi==0.9.1` implementation from [UM-ARM-Lab](https://github.com/UM-ARM-Lab/pytorch_mppi) matches the common clipped Gibbs update with identical noise, dynamics, costs, bounds and zero nominal. For a nonzero nominal, matching requires an explicit adapter disabling the reference's action-prior correction, because this project's policy-centered variant omits it. That is **not unmodified Williams-MPPI equivalence**. Reference version/source hash and tests are preserved in the core audit evidence. Independent action-cost/estimator definitions matter when choosing a paper baseline.

### Walker differential

Official Gymnasium1.2.3 / MuJoCo3.6.0, three identical full-state/action trajectories: stock-v5 observations diverge by maxima1.333,7.743,2.400 before termination. Instantiating official Gymnasium with the local XML yields exact physical-state/observation agreement for those sequences. Reward remains different: Gymnasium uses displacement/time; local `gymnasium` cost mode uses endpoint velocity. The frozen target-speed task and analytic failure reward tail are different again. [Evaluation audit](audit_evidence/evaluation_audit.md) gives formulas, termination, reset RNG details, source hashes and all runner seed domains.

## Evaluation freeze and power

The complete observable decision ledger is [evaluation_audit.md](audit_evidence/evaluation_audit.md), backed by raw server snapshots, exact checkpoints, source searches and git history. It includes Steps5–8 where only tracked historical decision records were available; those are explicitly weaker evidence. No audit can certify every undocumented human decision or deleted untracked artifact.

Reserve **5000000–5000199** for a final, once-only evaluation after source, task, methods, checkpoints, budgets, metrics and hypotheses are frozen. No member was evaluated in this audit. The collision scan covered420 text files,485 NPZ seed-array files, reachable source/config history and observed schedules; all returned no collision within that scope. [Reservation](audit_evidence/evaluation/fresh_reset_reservation.json).

For C1 against the stronger K256/H48 planner, use a5-percentage-point completion noninferiority margin and a separately measured inference advantage. With one-sided alpha.025,80% power, assumed true completion difference0 and bounded worst-case between-training-seed SD.5, the t-based planning calculation gives787 independent training seeds; the fixed conservative plan is **800 seeds ×200 final resets**. This is conditional on improving the method to an expected gap near0. Current development means.68 versus.88 are20 points apart: increasing sample size cannot rescue the current noninferiority claim. The large requirement is evidence that the claim/variance needs attention, not a reason to spend this compute immediately.

A smaller count requires a separate independent development pilot supporting a lower paired variance or a different explicitly justified margin. The seed-count calculation is conditional on the common reset panel: it does **not** establish 80% power over the population of reset states. Shared-reset variation contributes an uncertainty term that cannot be removed by adding training seeds. Population-level power needs a paired development pilot and a crossed training-seed/reset calculation before the number of final resets is frozen; the 200 reserved resets are a held-out panel, not a proven sufficient population sample. Learned-method comparisons such as C2 require paired **training-seed differences**, not the single-arm SD or thousands of correlated episodes. Sensitivity calculations and a nonoverlapping future training-seed schedule are saved in the power/reservation files. Do not treat all three proposed paper claims as automatically three identical statistical tests.
