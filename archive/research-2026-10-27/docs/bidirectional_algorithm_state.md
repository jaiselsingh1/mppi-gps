# Algorithm and evidence state

The research object is a bidirectional local-search/global-action-policy loop. It is not yet a successful physical-system result. This document distinguishes the implemented common interfaces, closed mechanism revisions, and the next prospective tests. Every closed run keeps its own frozen source and configuration.

The latest focused work is the [deployment-learning diagnostic](bidirectional_deployment_learning_findings.md). A changed actor improved one fresh 16-start qualification, but the complete repaired learning run failed ending generalization: the final matched children captured27/64 versus the retained parent's64/64. Neither feedback round promoted a guided teacher; independent and guided acquisition yielded identical children. The independent reference itself failed2/64 fresh final endings, retained in its cost. All three completed studies passed their arithmetic audits; the interrupted metric study remains operationally pending with closed query accounting. This candidate supplies actor learning with MPPI-acquired states but no explicit MPPI-informed agreement constraint, so its outcome gates are not an implementation of CIO-style joint teacher/student optimization. Its negative does not falsify that broader coupling idea.

The latest focused implementation is the [action-label-free return curriculum](bidirectional_return_curriculum_findings.md). Three new versions completed both matched feedback rounds, starting fresh actors and using no teacher action labels or critic. Final standalone actors captured64/64 on the cheap Ending task. The strongest version qualified actor-owned support and evaluated2,400 complete prefix/actor controllers; none beat strong independent search plus trajectory memory, even outside the support restriction. No handover executed, both next-student datasets were identical and the changed students regressed in complete cost. All three raw-evidence audits PASSed. The full beneficial loop remains unproven; this finding supersedes earlier pending status for this focused work and does not change older run verdicts.

## Raw objects and target ownership

| Object | Obtained from | What it establishes |
| --- | --- | --- |
| Physical snapshot | Simulator clock, joint state, capture progress, solver warm start and task identity | A restorable intervention context; observation alone is insufficient for physics restoration. |
| Executed episode | Actual controls, actual pre/post states and costs through the true episode terminal | A measured outcome of the named controller, including failures. |
| MPPI candidate bank | Paid simulations from one snapshot, with immutable actions, pre-action observations, native cost components and provenance | Hypothetical finite plans; a good score is not an executed episode or a global superiority claim. |
| Independent memory | Recorded independent executed continuations and remaining-time context | Candidate sequences to resimulate; it is not a policy labeler or a value predictor. |
| Stochastic actor return | Complete actual episode of one frozen behavior actor | Its Monte Carlo cost-to-go. It is never relabeled as the changed actor's return. |
| Actor-tail action comparison | One explicitly specified first action, then the same frozen actor through the true terminal | That actor's conditional continuation cost. It does not evaluate MPPI's future replanning or an updated actor. |
| Qualification record | Fresh paired complete controller executions | Finite measured support for a particular policy/version/family/influence setting. It expires when those bindings change. |
| Query/work ledger | Durable intent before simulation/inference/optimization, followed by completion or error | The charged expenditure and unresolved work; summaries do not replace raw evidence. |

## Protected search and acquisition

`IndependentSearch.propose(snapshot)` has no actor or critic input. Its private nominal, PCG64 state and independent memory produce K512 Gaussian plans, 32 broad plans and 16 memory/fallback plans. Every retrieved continuation is simulated again from the current snapshot. The Gibbs mean is a separately paid, verified alternative; retain the better native-task candidate between it and the best raw sample. Learned selection never updates that private nominal or memory. At an identical restored physical/private-planner state the proposal bank is identical despite a changed or deliberately bad actor. Guidance may change which states are visited.

The common executor distinguishes modeled plans from actual closed-loop controls. Teacher experience is eligible only after a complete executed outcome. Successful Acrobot episodes are separated by shoulder swing family; family identity is fixed during a rollout. Failed discovery attempts remain archived. The global actor cannot infer an unseen successful ending from a neural architecture or a short planner's preference.

## Global learning

The global component is a bounded, family-conditioned action policy with periodic physical observations, remaining time and capture context. Auxiliary action fitting can initialize it from a coherent successful family; that alone provides no reason to improve beyond teacher endings. The initial implemented learner additionally uses complete actor-owned stochastic episodes, repeated-context leave-one-trajectory-out baselines and clipped policy-gradient proposals. Training and deterministic deployment qualification are separate. The optimizer proposes; fresh full actor executions accept or reject.

The completed own-occupancy revision added a critic-free action-gradient surrogate. At actual current-parent states, it simulated bounded symmetric first-action perturbations followed by that same complete frozen deterministic parent. A four-control-prefix slope and a zero-slope update controlled the long-credit and inherited-optimizer explanations. All 800 branches captured; full and prefix signals nearly coincided. The full-signal child failed the predeclared .001 advantage over both controls. This is a retained coverage/learning negative, not evidence that long-term learning is impossible. See `bidirectional_own_occupancy_protocol_v0.md` and its closed run/diagnosis.

## Earned influence and learning feedback

A new actor version begins with zero planning influence. Uninterrupted actor-only suffix tests from acquired states and declared perturbations establish eligibility to try a bounded influence setting in tested support. They do not qualify improved MPC. Promotion additionally requires fresh paired **executed replanning** outcomes with complete-cost gain and capture nonregression. Unsupported support, changed policy identity, numerical failure or failed requalification restores the exact independent fallback. Teacher-to-student learning may continue with influence zero.

The first agreement-only revision reranked copied candidates using finite task score plus squared actor agreement. It failed the required capture panel on the cheap Ending task. A separate completed-tail revision kept the same independent bank and tested a small deduplicated set of first actions by complete frozen-actor continuations. Only the selected first action executed; planning repeated at the next actual state. It earned influence by independent qualification and confirmation panels, improved actual controller cost, and passed forced revocation. Its changed teaching data nevertheless failed to improve the matched next actor. That is a retained negative feedback link, not a successful whole loop.

The completed v5 early-context formulation started from the exact unsolved bootstrap. Initial long independent search acquired successful episodes; short independent search did not. The student executed its own complete suffixes from boundary 6 of each actual source episode. Matched children initially shared one ordinary-start panel; after a provisional update each changed actor collected fresh owner-correct data with matched work and noise. No new action labels entered training. Both half-step actors achieved 16/16 deterministic qualification capture, but the long-search-data child lost to the independently selected short-search-data child on complete cost. The initial data-advantage gate failed, so neither reserved feedback round nor the 64-root confirmation ran. The independent raw audit passed. Two beneficial feedback rounds and the separate three-seed frozen physical comparison remain required.

The subsequent coherent-return test replaced stochastic gradient updates with finite whole-policy parameter proposals around that same weak bootstrap. Five matched objectives used ordinary outcomes alone or mixed them with complete actor suffix outcomes from short/long-search states. All tested proposals were evaluated through actual complete controller executions. Ordinary-only, both short-data mixtures and one long-data mixture selected exactly the same final policy. The remaining long-data mixture retained more action noise and lost capture. All deterministic qualification controllers captured16/16, but no long-data actor beat the strongest ordinary/short-data control in both modes. Its independent evidence audit passed. This establishes learning an ending in this small policy subspace; it gives no data advantage or beneficial feedback result.

Saved-array diagnosis found that long-search acquired-state panels contained genuine ending contrasts, whereas the short-search panels contained none. It also found that the random head directions mostly resembled a constant bias on24 tested initial states, although nonconstant directions remained. This does not establish a global rank or capacity limitation. The separate state-informed geometry test used only saved pre-gate states to construct head perturbations, selecting every update using complete ordinary-start actor returns. It used no teacher action labels, acquired-suffix rewards or critic. All four learned actors captured16/16 deterministically. Long-source geometry improved stochastic capture to15/16 versus ordinary-source geometry's10/16, but lost deterministic complete cost1.905381 versus1.890182. The declared both-mode advantage gate failed; no64-root final panel ran. It paid66,600 scalar controls and66,888 neural rows in65.813 seconds. ## Assumptions, GPS interpretation and prior art

The weakest necessary coverage assumption is that independent search can acquire some complete useful behavior under the fixed native dynamics, bounds, start distribution and ending definition. A feasibility witness can support reachability, but cannot prove proposal coverage. Exact simulator restoration and numerical qualification are needed for branch measurements. Policy generalization and approximate optimization must earn acceptance through fresh complete executions; correct sampled labels or small fit error do not imply that acceptance. Additional distribution assumptions are required for claims beyond tested state support and start panels.

This fits GPS as a trajectory-centric local search coupled to a reusable global action policy, with local teaching and global learning influencing each other. The protected independent proposal channel and empirical promotion rules are engineering/research choices within that combined loop. An actor-free value-guided MPC pilot would test a mechanism, not establish standalone-policy GPS. The present actor-bearing prototype still needs beneficial repeated learning feedback and physical standalone evidence.

MPPI, GPS, policy gradients, rollout policy improvement, Q-filtered imitation, conservative outcome-based update acceptance and coherent action parameterizations have established prior art. Novelty of the exact combined formulation is not established by these implementation results. The contribution under test is whether the protected discovery channel plus measured long-credit learning and qualified feedback produces better *subsequent* standalone learning after all costs. No exploration or efficiency claim is currently supported.
