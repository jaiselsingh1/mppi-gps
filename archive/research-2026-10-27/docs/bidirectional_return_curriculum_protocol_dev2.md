# Actor-owned support, development revision 2

This is a separate outcome-informed development run. Preserve curriculum001
and002, their frozen sources, costs and negative verdicts. In002, fresh ordinary
capture was learned without action labels, but the actor's t4 suffix tests from
the teacher's state distribution passed only1/16. Guidance was therefore zero
in both rounds and no bidirectional advantage was measured. Teacher-state
coverage and search benefit were not distinguishable under that gate.

Change only the source of the existing16 t4 support tests. For each changed
actor, take the first eight actual complete ordinary qualification traces of
the selected actor (already paid and completed). From each recorded t4 state,
execute two uninterrupted suffixes after +/- .025 perturbations. These are
actor-owned states, not MPPI's teacher states. Bind all eight source traces and
full states in the trust request. Qualification outcomes may become development
support contexts afterwards; final evaluation remains untouched and never
feeds training or support. After a parent change, use its newly completed child
qualification traces; even an unchanged parent requires new tests after memory
changes. The new version starts at zero; >=90% ordinary and>=90% perturbed suffix
capture still only permit a provisional trial. Supported anchors must have
actually succeeded, with unchanged radius.15. A candidate prefix ending outside
that measured support cannot hand over. No generalization certificate is claimed.

This hypothesis tests whether restricting guidance to demonstrated actor
competence, instead of requiring transfer to a teacher's different preparation,
allows protected MPPI prefix search to exploit an actually executable ending.
If supported candidates cannot improve the strong RAW controller, retain that
control failure. If the teacher improves but matched students do not, retain
that bidirectional learning failure. Do not relax criteria to obtain promotion.
