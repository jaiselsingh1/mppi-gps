# MPPI–GPS

This project develops a standalone action policy and an independent MPPI teacher that improve one another. The beneficial feedback loop is **not yet established**. Current trained actors and new learning results are from the cheap **Ending** mechanism task. There is no new-method Walker deployment.

Read [the algorithm](docs/algorithm.md), [current evidence](docs/results.md), then [the code map](docs/code_map.md). Use one public entry point:

```sh
.venv/bin/python -m scripts.training.train_bidirectional_gps status
.venv/bin/python -m scripts.training.train_bidirectional_gps validate --out-dir runs/core_check_new
```

Workflow in fresh directories. The v43 component must pass before full `develop` accepts `--interface-run`; the gate binds critical learner source and actual outcomes. The component uses the original rejected v42 GUIDE13 actor only for diagnosis. Full development starts the preserved qualified theta14 input parent, with fresh roots and no imported frontier authority. The commands below create new runs; they do not alter the completed runs:

```sh
.venv/bin/python -m scripts.training.train_bidirectional_gps mechanism --active-endings \
  --config configs/bidirectional_ending.json \
  --source-run runs/2026-10-28_realized_admission_cycle_001 \
  --out-dir runs/interior_ending_update_new

.venv/bin/python -m scripts.training.train_bidirectional_gps develop \
  --config configs/bidirectional_ending.json \
  --source-run runs/2026-10-28_realized_admission_cycle_001 \
  --interface-run runs/interior_ending_update_new \
  --out-dir runs/interior_ending_cycle_new

.venv/bin/python -m scripts.training.train_bidirectional_gps report \
  --run-dir runs/interior_ending_update_new --out-dir runs/interior_ending_update_report_new

.venv/bin/python -m scripts.training.train_bidirectional_gps report \
  --run-dir runs/2026-10-28_interior_ending_cycle_001 --out-dir runs/interior_ending_cycle_report_new

.venv/bin/python -m scripts.training.train_bidirectional_gps report \
  --run-dir runs/2026-10-28_teacher_constraints_probe_001 \
  --out-dir runs/teacher_constraints_probe_report_new

.venv/bin/python -m scripts.training.train_bidirectional_gps mechanism --branch-credit \
  --config runs/2026-10-28_realized_admission_cycle_001/config.json \
  --source-run runs/2026-10-28_teacher_constraints_probe_001 \
  --out-dir runs/native_branch_credit_probe_new

  --run-dir runs/native_branch_credit_probe_new --out-dir runs/native_branch_credit_report_new
```

Run directories are create-only. Every experimental run freezes source, settings and inputs before queries; verification and failed work are charged. Core validation blocks physics and neural execution. Existing baseline MPPI runners remain under `scripts/runners/`; they are separate from the protected research search.
