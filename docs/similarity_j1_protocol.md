# J1.0: prospective similarity and fixed-update learning

This is one bounded investigation authorized by the attached user request. The prospective launch recipe is [similarity_j1_0.json](../configs/studies/similarity_j1_0.json). Its objective is a **pre-update scalar that predicts post-update standalone walking and independently executed teacher-motion reproduction**. This is not a trajectory-optimization intervention. Existing interfaces, the Walker task, width128 torque learner, observations and optimizer arithmetic remain unchanged. No critic, architecture contrast, new environment or automatic follow-up is allowed.

## Case and identification

A learning case is `(group, learner, source)`: one complete incoming learner package, one corpus and exactly 2,000 updates. Eight development groups and eight protected groups each acquire one independent-MPPI and one fixed-SAC-reference trajectory from the same fresh reset context. Each group has two fresh learner streams; each incoming state branches into its two source cases. Thus the maximum is 64 fits, 32 independent incoming packages, 16 MPPI trajectories and 16 reference trajectories. Source and learner groups are disjoint across development/final. Related records never become additional independent replications. A new source-acquisition group is defined by a fresh full reset, fresh private planner state/RNG and two fresh learner streams; both provider trajectories and all their derived data remain in that group. These are repeated acquisitions within one fixed software/task/reference condition, not sixteen independent algorithm/configuration studies. No historical source-run trajectories are split across development and final; historical learned reference weights and W1 normalization are fixed shared conditions, not claimed new independent teachers. The uncertainty claim is conditional on those fixed conditions.

Each eligible corpus is one complete 1,000-control episode and exactly 1,000 unique executed state–action rows. Every attempted teacher, including failure, is preserved. A short source has no padding, replacement or additional acquisition: its two fits are marked ineligible, while other declared cases continue. Source walking is reported, not used to select scores or silently discard a full-length corpus. Single-trajectory corpora identify a case's reproduction target; no mixed-child outcome is attributed to individual examples.

The two source cases for a learner share exact incoming tensors, 17-input W1 normalization, empty initial Adam state, private/global Torch states, PCG64 state and a presealed `[2000,256]` minibatch-index tape. Normalization is the original development-only W1 rule, never refitted on protected data. The original fit implementation uses batch256, learning rate0.0003, Adam(0.9,0.999), epsilon1e-8, weight decay0, gradient clip0.5, proximal weight0, anchor refresh0, CPU float32 and Torch threads1. All checkpoint/optimizer/RNG/tape/row bindings precede fitting. No parent is refitted. A copied SAC actor is an execution control, not a successful learning case.

## Outcomes and execution

Every incoming and updated learner executes directly, with no MPPI fallback. Incoming execution is one same-start rollout per learner, reused across its two identical-context source contrasts; there is no incoming16-reset panel. Each updated case receives 16 fresh standalone resets shared within its group/learner/source contrast. Reset IDs are disjoint from acquisition and between development/final. Walking is the existing 1,000 actual controls, no fall, full-window mean absolute forward-velocity error from1.5 at most0.3. Survival, actual-prefix velocity error, native running/fall costs and complete absorbing-tail cost are separate. This single16-reset panel does not establish the project's two-panel individual-competence criterion.

For reproduction, replay recorded teacher actions first from the exact initial integration snapshot; require byte-exact restoration and returned state/warmstart/integration/observation/native-cost agreement at rtol0/atol1e-10. Execute the incoming and updated students independently from that same context. Failure stops that case's reproduction certification; never loosen tolerances. All actual failing prefixes and terminal contexts remain saved. No post-fall state is fabricated.

Continuous motion error is the square root of the time average of four equally weighted components: squared relative-progress error/(1m)^2; squared height error/(0.25m)^2; mean squared wrapped differences of seven angles/(0.5rad)^2; mean squared nine velocity differences/(3SIunits)^2. Each component is capped at9. Add4 per missing fraction of the1,000-control window inside the square root. Save uncapped components too. Root progress subtracts each trajectory's initial root position. Time is synchronized; no time warping, phase alignment or best-path selection.

Binary reproduction requires the full1,000-control window without a fall, joint-angle RMS≤0.25rad, forward-velocity RMS≤0.3m/s, height RMS≤0.1m and final relative-progress error≤0.5m. Walking with another gait remains valid walking even if reproduction fails. A fallen trace's prefix error is not a full-window outcome.

## Five frozen pre-update candidates

All distances are lower-is-closer; save all components and rejected calibrations. Scores and predictions must be sealed before the learning update they predict. One incoming teacher-state prediction array and one independent incoming same-start execution are shared by all scores. With one trajectory per corpus, corpus score equals its trajectory score; any later mixed-corpus version must use declared trajectory-equal aggregation.

1. **A: action MSE**, mean squared teacher/policy torque difference over all six actions and1,000 states.
2. **B: smoothed-action MSE**, the same calculation after the same fixed five-control causal box filter on both tapes, using only valid controls4…999. No padding beyond a fall. Smoothing may remove consequential differences; benefit is untested.
3. **C: state-explained proxy**, fit one affine ridge map `m(o)` from the actual normalized17-dimensional observations to teacher actions using development teacher rows only; ridge1e-3, unpenalized intercept, no protected refit. Score `mean((m(o)-pi(o))^2) + 2*mean((u-m(o))^2)`. The coefficient2 is a fixed untested hypothesis. Publish both terms, residual support and rank. Residuals can reflect model misspecification/support shift and are not identified irrelevant noise. C is a proxy rather than an identity metric: an exact nonlinear teacher–policy copy can retain nonzero affine misspecification residual. No privileged coordinate enters C. Hidden-coordinate and planner-memory perturbations are diagnostic controls only.
4. **D: motion distance**, the continuous metric above between the teacher and independent incoming-policy execution from identical context.
5. **E: joint occupancy distance**, mean squared sliced-Wasserstein distance of actual17-observation/6-action joint pairs, using32 fixed PCG64-seeded unit directions and1,000 fixed midpoint quantiles. Standardize these23 coordinates using development teacher/incoming rows only, standard deviation floor0.05. Add4 times incoming missing-control fraction as a separate cemetery-mass penalty. No synthetic post-fall physical samples are added. Joint-pair ordering invariance is intentional and a limitation.

Calibration must verify exact copies; known affine feedback and held-out gain perturbations; identical-observation contradictory actions; contact spikes/dropouts; changed joint coordination; time-shuffled joint pairs; shuffled predictive labels; and the identities that equal-weight orthonormal Fourier squared error and squared action-law Wasserstein distance to a deterministic action reduce to MSE. Explained-component-only C and those algebraic aliases remain rejected-candidate rows, not renamed discoveries.

## Development, protection and prediction

No historical already inspected result is a protected final label. Development inputs/outcomes may be inspected once; J1.0 allows no score/parameter sweep. Freeze the affine explanatory map, occupancy normalization, all five scalar standardizations and prediction coefficients before protected fitting. Final labels remain sealed until the whole final roster and independent score-time/checkpoint joins close. No final inspection followed by renaming or tuning is allowed.

Every score receives identical prediction capacity: intercept plus one standardized scalar. If development walking labels have one class only, use the same fixed smoothed constant probability `(successes+0.5)/(trials+1)`, slope0 and an explicit ineligibility flag for every score. Otherwise fit ridge1 linear regression (unpenalized intercept) for `log1p(post-update motion error)` and ridge1 binomial logistic regression for standalone walking rate. Motion predictions invert log1p and clip to the shared known range[0,3]. Brier loss is the proper per-episode Bernoulli mean, not squared error of an observed case rate. Fixed deterministic numerical solver/tolerances; no source indicator or candidate-specific extra predictors. Preserve unchanged-incoming prediction and post-update gain as descriptive controls.

Primary comparisons concern the **protected MPPI stratum**. Pooled/reference results are separate and cannot manufacture MPPI walking discrimination. Require eight eligible protected source groups and at least four MPPI cases with at least1/16 walking and four with zero, with positives across at least three groups/streams. Otherwise walking prediction is unidentified. Continuous motion requires development and protected MPPI standard deviation≥0.1 and at least eight groups; otherwise it is also unidentified. Binary reproduction discrimination needs both classes and is reported separately.

For the same candidate to pass the full objective, require ≥10% lower protected MPPI motion-prediction RMSE than A and walking Brier improvement≥0.02 absolute and≥10% relative. Both improvements require positive simultaneous95% lower confidence bounds over all four candidate-versus-A contrasts and both outcomes, using9,999 paired source-group bootstrap resamples. Group resampling retains both learner streams and source cases. Report limited finite-benchmark uncertainty; do not bootstrap frames or resets as independent learning cases. A partial motion result cannot pass walking or authorize guidance. If development walking variation is absent, retain that ineligibility; protected motion may still be tested once if its variation gate passes.

## Relation to established work

[DAgger](https://proceedings.mlr.press/v15/ross11a.html) addresses action-dependent observation distributions; it does not validate a pre-update teachability score here. [PWIL](https://arxiv.org/abs/2006.04678) uses state–action distribution matching; J1.0 tests a diagnostic score rather than adopting its learning algorithm. [PSM](https://arxiv.org/abs/2101.05265) defines policy-sensitive behavioral state similarity, not this fixed-update learning-case target. [Owen’s bootstrap analysis](https://arxiv.org/abs/0712.1111) warns against naive resampling with crossed dependence; J1.0 instead nests its two learner streams inside fresh source groups and resamples whole groups. None supplies a guarantee with eight protected groups or establishes novelty or benefit here.
