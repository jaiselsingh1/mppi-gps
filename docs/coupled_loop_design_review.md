# Coupled-loop design review — completed eight-round evidence

All **8 rounds × 3 streams** finished: **0/192** final walking; survival **2/96 coupled, 0/96 static**. This saved-only review covers **112,856 banks / 28,891,136 candidates**. The original final audit remains **CLOSED_UNCERTIFIED**: a typed JSON-list/array comparison failed. All 157 saved probe actions match numerically exactly, but unexecuted audit checks remain uncertified. No audit, physics, inference or fitting was repeated. [Evidence, sources and costs](../results/coupled_loop_design_review_001/README.md).

1. **Restarts never follow updated students.** All eight contexts are controls **1,17,34,51,67,84,101,118** of one failed 236-control original-student rollout. Updated policies change teacher paths, not restart selection. “Own rollouts” are MPPI's; student evaluation probes never train it. Across 190 final falls, terminal nearest-training RMS distance is **1.758/1.577** to current data and **1.636/1.467** to ancestral data (static/coupled; fixed normalization). This describes support, not causation.

2. **Alpha zero becomes static refitting.** After round one, its inputs/labels remain byte-identical, including learner float32 arrays. It controls conditioning at fixed starts; it is not DAgger, which labels current-student visited states and aggregates them.

3. **Admission restricts coverage.** Static has **15 changed / 105 identical / 72 fallback** episodes; coupled **120/0/72**. Thus policy-to-teacher feedback is real. The cost ceiling alone rejects **40 static / 50 coupled** locally walking, surviving episodes. Every old restart remains represented; rejected trajectories provide no fitting rows. [All 48 cells, including learner-visible novelty](../results/coupled_loop_design_review_001/admission_table.md).

4. **Prefix dependence is strong; aggregate weight changes are small.** Within-bank coupled D-versus-length slope is **1.183/control**, R² **.642**. D covers executable prefixes; post-fall discrepancies remain absent. D/N changes the top candidate in **6,978/56,864** banks, while weakening full-horizon scale. Scale-matched **48D/N** changes **151/56,864**. Mean surviving-candidate weight moves **99.2052%→99.2118%** (scaled **99.2087%**). These counterfactual weights establish no executed benefit.

5. **Coupling is weak:** median std(alphaD)/std(C)=**.0318**. In the earlier eight-slot contrast, one avoided-fall episode improves cost **571.46**, exceeding the net **518.43** gain; its fall charges contribute **530**, and the other seven slots worsen **53.03**. [Every bank](../results/coupled_loop_design_review_001/per_bank.csv.gz), [slot accounting](../results/coupled_loop_design_review_001/earlier_slot_costs.csv).

6. **Predictability partly recovers, without progressive improvement.** Coupled >5 Hz Welch power is **60.13%→59.61%** at rounds 1→8; high-pass-residual variance is **57.96%→57.72%** (static **58.92%** unchanged). Leave-one-restart-trajectory-out low-band R² moves **.373→.290→.334** (rounds 1/5/8); full-action R² **.100→.067→.080**; high-band **−.080→−.089**. Static low/full/high R² stays **.304/.064/−.085**. All trajectories share one original rollout. [Both arms, all rounds and burn-in sensitivity](../results/coupled_loop_design_review_001/spectra.csv); no SAC inference or learnability gate.

7. **Training improves while held error worsens.** At 2,000 updates on 2,400 rows per round, static training/held MSE moves **.0926/.2496→.0237/.4202**; coupled **.0975/.2394→.0658/.3039**. This supports distribution-specific fitting, not a unique explanation for falling. [Curves](../results/coupled_loop_design_review_001/fit_and_predictability.png).

8. **Warm-start benefit remains untested.** All 384 episodes start with zero plans; later controls shift plans. Initial refinement raises candidate survival **2.67%→15.71% static / 15.54% coupled**, but also changes random draws. No saved same-context, same-random cold/warm contrast exists. One paired restart with identical innovations, zero versus retained same-context plan, would test execution changes before fitting.

**(a)** This completed loop tests learning from policy-conditioned teacher paths at fixed old starts; useful standalone transfer failed. **(b)** Fixed restarts and static refitting invalidate current-student corrective-acquisition or DAgger-superiority claims. Arm-specific incoming policy/Adam parents also confound isolated attribution to these eight rounds. These limitations do not establish numerical invalidity.

**(c) Proposed, not launched:** one matched 2,000-update, 2,400-row pilot on current-student states: coupling with **5.76D/N** fixed before fitting; true alpha-zero DAgger; 5 Hz-filtered cloning. Match policy/Adam/RNG, architecture and end-to-end CPU/forward costs, allocating baseline savings to useful acquisition before outcomes. Freeze data selection and 16 unused paired resets. Discard coupling if teacher competence regresses or it gains fewer than **2/16 walking successes over either control**; any positive result needs fresh confirmation.
