# C1.0-A2: certificate-only compensating closure

This is a distinct administrative continuation of the user-authorized C1 audit recovery. It is not an A1 retry or a new research experiment. The A1 stopping rule was honored: its 765-file/journal verification is not repeated, and its failed admission remains failed. S1.2 remains review-only.

## Why this step is needed

A1's verifier completed its checks in 13.278 seconds: 765 deduplicated file bindings, 2,913,157 journal records, all saved scalar rosters, gates, curves and costs reconciled. It read 3,450,578,828 bytes with zero inference, physics, fitting, checkpoint tensor loads or task evaluations. The preserved child receipt records exit zero and reaping, **alongside** a coordinator exception, kill request and conservative unknown-partial flag. Neither that receipt nor the failed external observer is relabelled clean.

Both launchers hit the same exit/RSS boundary. The previous fix covered disappeared and zombie/dead process states but was too narrow for address-space teardown before the final task-state transition. The current watchdog polls every iteration and, if RSS is unavailable, accepts that condition only after an actual child exit is confirmed within a short bounded wait. A still-live child without measurable RSS fails closed. Frozen A1 source and failure bytes are untouched; current-source software fixtures test the correction separately. The exit-window explanation is an inference from the traces and the kernel’s separate [status/memory reporting](https://raw.githubusercontent.com/torvalds/linux/master/fs/proc/array.c) and [address-space teardown](https://raw.githubusercontent.com/torvalds/linux/master/kernel/exit.c); the exact transient A1 status line was not captured.

The original C1 scientific receipt remains the numerical certification. A1 provides a completed **point-in-time integrity/accounting certification** with a genuine worker exit zero. A2 authenticates only those small certificates and observes a clean new closing chain. It does not newly hash all original payloads, rerun their journals, recompute network outputs or invent any missing historical exit.

The [A2 recipe](../configs/studies/student_consequence_c1_certificate_closure_a2.json) pins the original C1 scientific receipt/failure, A1's result and verified-file catalog, configuration, source/input manifests, ownership, genuine worker exit, three producer-source files, and both launcher failure records. All anchors use exact whole-file sizes and SHA-256, rooted under four explicit read-only trees. The input manifest must identify A1 source commit `a5418a5c8285f27bda9eb9e0f9a7b085aadd3c4a`; its original pure-stdlib auditor SHA is `9be518ff8e4d691d8107ab7a8383f758b1a83a1159dd26c409f7ea184d0c4bc1`.

Require A1's passed certificate, matching canonical protocol SHA, exact 765-entry verified catalog and its hash, source/config/ownership joins, recorded worker exit zero and reaping. Preserve its `coordinator_exception`, kill-request and unknown flags as recorded. Require the original C1 pass certificate and matching retained binding, with original child exit still unknown. Missing/mismatched/escaping/symlinked/changing inputs or altered failure flags stop the new attempt.

A minimal immutable source bundle contains only the stdlib certificate verifier, observer and an exact frozen excerpt of the corrected canonical watchdog. No array or checkpoint is decoded. No original evidence tree receives any output; no A1 candidate, exit or admission is created or replaced.

## Bounded closing sequence

| Boundary | Ceiling |
|---|---:|
| Whole A2 stage | 60 seconds |
| Certificate worker / external coordinator / finalizer | 30 / 45 / 15 seconds |
| Per-process RSS / pinned CPU cores | 512 MiB / 1 |
| Certificate reads | 32 MiB |
| Coordinator, finalizer and outer-observer metadata, each | 32 MiB |
| Total stage explicit reads | 128 MiB |
| Single anchor / anchor count | 2 MiB / 32 |
| All A2 output, including its minimal source | 4 MiB |
| New scientific work | Zero of every declared counter |

Debit a conservative prior upper reservation of **600 seconds and 16 GiB reads** for all original and A1 audit work, including failed closing work. These are upper reservations, not measured charges. Add the full new 60-second/128-MiB envelope before checking the original two-hour/64-GiB cumulative audit ceilings. The original four-GiB audit-output and sixteen-GiB study-output ceilings remain in force. Source transfers and collection share the still-bounded recovery publication allowance and are separately counted; no raw payload is transferred.

Freeze and publish A2 source/protocol before execution. A worker writes only a certificate-check result. Its coordinator must observe genuine clean zero exit, then write an unresolved candidate. An external observer must observe that coordinator close cleanly before invoking the bounded finalizer. The finalizer authenticates the candidate and closing bindings, writes a new A2 compensating admission, and must itself be observed to exit cleanly. Publication requires all three real closing receipts. Every enclosing watchdog catches and retains exception receipts rather than discarding them.

Any check, ownership, read/time/memory/output limit or closing failure stops and preserves this attempt. No failing predecessor is upgraded and no source or gate is silently replaced. The accepted scope, if this passes, is **retained original numerical certification plus retained A1 integrity/accounting certification, admitted by a clean A2 closing process**. It is not a claim that A1 passed its own frozen outer gate or that all 765 files were rehashed again at A2 time.

After closure, publish both failure chains and costs alongside the new receipt. Bind that receipt into the versioned [S1.2 review protocol](student_visitation_s1_2_protocol_v2.md). No reference takeover, label query, new fit, architecture intervention, evaluation or coupling stage is launched automatically.
